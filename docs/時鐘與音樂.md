# 時鐘與背景音樂（右上角）

## 畫面
- 群島畫面右上角（原本「音樂：開」按鈕的位置）是一個小卡片：
  - 中間是**數字時鐘**，24 小時制，**台灣時間（GMT+8）**。不管平板或電腦設定在哪個時區都一樣，每換一分鐘更新。
  - 時鐘左右的**三角箭頭**：◀ 上一首、▶ 下一首（繞一圈）。換歌時下面那行先寫「第 2 首・花園散步」，2 秒後變回「♪ 花園散步」。
  - 最下面是「**關掉音樂**」按鈕；關掉後變成「打開音樂」，時鐘變灰，歌名那行寫「音樂關著」。關著也可以先選歌。
- 選的歌和開關記在這台裝置（`localStorage` 的 `elementa.song`、`elementa.muted`），下次打開照舊。
- 音樂照樣是小孩第一次點畫面（「點一下出發」）後才開始（瀏覽器規定）。
- 上方列變高了（手機上會換成兩行），島和建築的清單、登入卡片會自動放在上方列下面，不會蓋住時鐘。

## 參數和怎麼加歌
| 檔案 | 用途 |
|---|---|
| `config/music.json` | 歌單（旋律、低音、速度、音色）、音量 `volume`、時鐘的時區 `timeZone`（`Asia/Taipei`）。可以直接改 |
| `tools/compose_music.py` | 作曲程式：每首歌寫下調、速度、拍子、樂器、和弦進行、兩個動機，照固定曲式（A 段 8 小節、B 段 4 小節、A 段回來 4 小節、停在主音）展開。要加歌：在 `SONGS` 加一筆，執行 `python3 tools/compose_music.py`，會重寫 `config/music.json`。網站不用這個程式 |
| `config/text.json` | `music`：上一首、下一首、關掉音樂、打開音樂、歌名那行、時鐘的朗讀文字 |

`music.json` 一首歌的格式：`notes` 一格是八分音符，`-` 表示延長上一個音；`bass` 每 `bassEvery` 格一個低音；`instrument` 是 `musicbox`（八音盒）、`marimba`（木琴）、`celesta`（鋼片琴）、`kalimba`（拇指琴）、`harp`（豎琴）、`flute`（笛子）、`bell`（小鐘）。

## 程式
| 檔案 | 做什麼 |
|---|---|
| `world/music.js` | 音樂盒：歌單整理（`songList`）、七種音色（`INSTRUMENTS`）、換歌時舊歌淡出（`setSong`／`next`／`prev`）、關掉後讓音效暫停省電 |
| `world/clock.js` | `clockText(ms, timeZone)`：台灣時間 24 小時制（時區寫錯就用 +8 自己算）；`msToNextMinute` |
| `world/hud.js` | `setMusic()` 畫時鐘卡片、`startClock()` 讓時鐘走；上方列的高度存在 CSS 變數 `--hud-top` |
| `world/main.js` | 讀 `config/music.json`，接上一首、下一首、關掉音樂 |
