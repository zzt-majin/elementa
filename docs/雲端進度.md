# 登入與雲端進度（engine/cloud.js、world/account.js）

小孩用試算表「帳號」工作表的密碼登入。交卷後成績送到家長自己的 Google 試算表，換一台裝置登入時，試算表的進度會合併回來。後台程式是 `backend/` 的 Google Apps Script（清單版「考卷補分站」用的是同一個後台）。

## 檔案分工

| 檔案 | 負責 |
|---|---|
| `engine/cloud.js` | 登入、讀進度、存成績、待存清單（沒網路時排隊，之後補存）。不碰畫面 |
| `world/account.js` | 登入卡片和上方列的同步狀態；用 `startWorld` 的 hooks 接上，`main.js` 不知道它存在 |
| `world/login.css` | 登入卡片的樣式 |
| `config/backend.json` | 後台網址和參數 |
| `config/text.json` 的 `login` 區 | 畫面上的字 |
| `engine/progress.js` 的 `merge()` | 把試算表的進度合併進這台裝置，好的留下 |

## config/backend.json

| 欄位 | 預設 | 意思 |
|---|---|---|
| `api` | 空白 | Apps Script 網頁應用程式網址，只接受 `https://script.google.com/macros/s/…/exec`。空白時不登入，成績只存在這台裝置 |
| `timeoutMs` | 15000 | 等後台回應最久幾毫秒 |
| `queueMax` | 200 | 待存清單最多留幾筆 |

## 流程

1. 打開網站：`api` 有填、這個小孩還沒登入時，左上出現登入卡片。可以按「先不登入」，成績先存在這台裝置。
2. 登入成功：拿到通行碼（存在 `localStorage` 的 `elementa.cloud.session`），把試算表的進度合併回來，再把待存的成績送出。
3. 交卷：`hooks.onResult` 把成績排進待存清單（`elementa.cloud.queue`），已登入就馬上送。錯題重練也會送，後台記在「作答紀錄」，不算進「進度」的最佳成績。
4. 沒網路：成績留在清單，連上網路、切回這個分頁、重新打開網站時再送。
5. 密碼改過：後台不認舊通行碼，網站登出並請小孩重新登入，登入後補存。
6. 後台說格式不對的紀錄會丟掉，只留在這台裝置，不會卡住後面的。
7. 蓋橋：`hooks.onBuild(kid, build)` 把建設排進同一個待存清單（`type: 'build'`），送到後台的 `build` 動作，記在「建設」工作表。後台還是舊版、不認得時，建設留著下次再送（不丟），不擋後面的成績。清單太長時只擠掉最舊的成績，不擠掉建設。登入、讀進度、存成績時，後台會把這個小孩的建設一起傳回來（`builds`），網站合併後重畫橋。

合併規則和最佳成績相同：答對多的好，一樣多時用時短的好。試算表沒有記第一次全對的時間，雲端已全對時 `perfectAt` 記成 `cloud`，之後在這台再全對不會被當成第一次（給歐巴幣用）。

家長在試算表「設定」填的規則（學習卡開放時機、搶答賽秒數…）會在登入或讀進度時一起拿回來，存在 `elementa.cloud.settings`；之後的學習屋、搶答賽用 `account.settingsOf(kid)` 讀。

## 給 hooks 的接口（world/main.js）

| hook | 什麼時候呼叫 |
|---|---|
| `onReady(world)` | 群島畫好後一次。`world = { progress, text, kids, kid(), refresh() }` |
| `onKidChange(kid)` | 切換小孩時 |
| `onResult(summary, info)` | 每次交卷後 |
| `settingsOf(kid)` | 群島要讀試算表「設定」時（學習屋用）。沒登入過回傳 null |
| `onBuild(kid, build)` | 蓋好一座橋時（存到試算表「建設」） |

## 個資與資安

- 網址會公開在 repo 裡。它只接受登入和存進度，不回傳密碼；密碼錯會等 0.5 秒，減慢亂猜。
- 試算表本身不要公開分享。密碼用沒在別處用過的簡單密碼。
- 通行碼存在小孩那台裝置的瀏覽器。共用電腦用完按「登出」。
- 送到試算表的只有：稱呼、關卡代號和名稱、答對題數、題數、用時、是否時間到、是否錯題重練；蓋橋時是哪座橋、花多少。每題的答案不送。
