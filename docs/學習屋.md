# 學習屋（engine/cards.js、world/cards-ui.js）

學習屋放學習卡：關卡裡每一題做成一張卡，正面是題目（選擇題附選項），點一下翻到背面看正確答案和解題技巧。看完一張可以按「我會了」或「再看一次」，一輪看完後可以只重看「再看一次」的那幾張。

卡片直接從關卡的題目做出來，不用另外寫內容。出題模組的關卡每次打開學習屋都會換一批新的例題。

## 什麼時候打開

| 試算表「設定」的「學習卡開放」 | 程式代號 | 打開條件 |
|---|---|---|
| 一開始 | `always` | 關卡有題目就打開 |
| 測驗後 | `afterQuiz` | 在測驗塔交過一次整關（0 分也算）。錯題重練不算 |
| 全對後 | `afterPerfect` | 這一關的最佳成績是全對 |

- 每個小孩分開設定，登入時從試算表拿回來（`account.settingsOf(kid)`，經 `startWorld` 的 `hooks.settingsOf` 傳進群島）。
- 還沒登入、試算表那一格空白或填錯字時，先看 `config/cards.json` 的 `bySubject`（照科目，現在英語是 `always`：一開始就打開，背單字用），沒列的科目用 `defaultRule`。
- 學習屋清單最上面會寫現在照哪一種規則，以及是照試算表還是預設。
- 還沒打開的關卡會說要先做什麼，並有「去測驗塔寫這一關」按鈕；交卷後按「回到學習屋」，打開的卡馬上看得到。
- 家長改了試算表設定，小孩下一次登入、切回分頁或連上網路時會重新讀，學習屋清單跟著更新。

## 檔案分工

| 檔案 | 負責 |
|---|---|
| `engine/cards.js` | 開放規則、試算表說法對應、做卡片、一輪看卡（翻面、換張、記號、結果）。不碰畫面 |
| `world/cards-ui.js` | 看卡畫面和一輪結束畫面 |
| `world/cards.css` | 看卡畫面和學習屋清單的樣式 |
| `world/hud.js` | 學習屋清單（每一關能不能看、要先做什麼） |
| `world/main.js` | 把規則、進度、畫面接起來 |
| `config/cards.json` | 參數 |
| `config/text.json` 的 `cards` 區、`houseBody` | 畫面上的字 |

## config/cards.json

| 欄位 | 預設 | 意思 |
|---|---|---|
| `defaultRule` | `afterQuiz` | 沒有試算表設定時用哪一種（`always`／`afterQuiz`／`afterPerfect`） |
| `bySubject` | `{ "英語": "always" }` | 照科目的預設，比 `defaultRule` 優先；試算表有填還是照試算表 |
| `sheetValues` | `一開始`、`測驗後`、`全對後` | 試算表那一格可以填的字，各對應哪一種。賣給別人、換語言時改這裡，不用改程式 |
| `showOptions` | true | 選擇題卡片正面要不要列出選項 |
| `shuffle` | false | 每一輪是否預設打亂順序（畫面上也有按鈕可以切換） |

## 個資

「我會了／再看一次」只留在這一次的畫面，關掉就清掉，不存進裝置，也不送到試算表。

## 測試

```
node tests/cards.test.mjs   # 規則、對應、卡片內容、一輪看卡，並把每一關實際做成卡片
```

## 英語學習卡（2026-11-28）
- 英語關卡的卡片不是「一題一張」，而是從教材檔（`content/words/*.md`）來：關卡檔 `cards:` 寫要哪幾段（例如 `places, activities, extras`）。
- 正面：圖＋英文，卡片下面有「🔊 聽」「🐢 慢慢聽」；背面：中文＋例句或說明。補充字（`extras`）只放卡片，不考。
- 程式：`engine/words.js` 的 `bankCards`，出題模組 `materialize` 時放進 `level.cards`，`engine/cards.js` 的 `buildCards` 看到就用它。
