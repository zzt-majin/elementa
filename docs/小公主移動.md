# 3D 小公主、島的大小、鏡頭、地圖（世界設定第 2＋3 步）

## 玩法
- 一進群島就是「走路模式」：鏡頭從斜上方跟著小公主，小公主一直在畫面中間。
- **電腦**：方向鍵或 WASD 走路，方向就是畫面的上下左右。走到建築門口，畫面下方跳出「進入測驗塔／學習屋／遊戲帳篷」大按鈕，按**空白鍵**（或 Enter）或點按鈕就進去。Esc 關掉清單。
- **平板**：點地面，小公主就走過去；點建築，小公主會走到它的門口，再按「進入」。點海裡會走到岸邊。按住拖曳是轉鏡頭（最多左右 35 度），不會走路；兩指可以小幅拉近拉遠。
- 小公主不能走進海裡、不能穿過建築和樹，碰到會沿著邊滑開；被擋住走不過去會自己停下來。一開始只能在自己的數學島上走，蓋好橋才能走到別的島（`docs/蓋橋.md`）。
- **右上角「地圖」**：鏡頭拉遠看全部的島，點任何一座島就打開它的建築清單（沒蓋橋也能學）。按鈕會變成「回到小公主」，再按一次回去。
- 切換姐姐／妹妹：小公主回到數學島的出生點。

## 參數都在設定檔
| 檔案 | 欄位 | 用途 |
|---|---|---|
| `config/subjects.json` | `position`、`size` | 每座島的位置（公尺）和大小倍率。島和島之間至少留 15 公尺海，之後放橋 |
| `config/world.json` | `island` | 島的基本半徑（23.4，原本 5.2 的 4.5 倍）、邊數、小花和樹的數量、浮動（設 0） |
| | `village` | 島中間小村子：三棟建築的位置和角度、建築大小、出生點、門口多近會出現按鈕 |
| | `avatar` | 小公主站哪座島、走路速度、身體大小、膚色、髮色、皇冠色（裙子用選的公主代表色） |
| | `camera.follow` | 跟隨鏡頭的距離、高度、預設方位、拖曳最多轉幾度、跟上的快慢、拉近拉遠範圍 |
| | `camera.overview*`、`focus*` | 地圖模式看全部島的位置、點島飛過去的距離 |
| | `sea`、`fog`、`shadow` | 海的大小、霧的遠近、陰影只畫鏡頭附近多大 |
| `config/text.json` | `hint`、`walk` | 提示文字、「地圖」「回到小公主」「進入{name}」 |

## 程式
| 檔案 | 做什麼 |
|---|---|
| `avatar/princess.js` | 3D 小公主模型（原創低多邊形）和走路動畫。`parts` 留給之後更衣室換裝 |
| `avatar/walk.js` | 走路規則（不碰 3D，可以用 node 測）：草地邊界、擋路的圓、沿邊滑、點地面走過去、卡住停下、門口判斷、畫面方向換成地面方向 |
| `world/controls.js` | 鍵盤：方向鍵／WASD、空白鍵、Esc。打字中、作答中、面板打開時不攔 |
| `world/camera.js` | 兩種鏡頭：`follow`（跟著小公主）、`free`（地圖：繞著轉、飛到島） |
| `world/islands.js` | 蓋島和小村子；每座島的 `userData.walk` 記下草地半徑、擋路的圓、門口、出生點；`walkAreaOf()` 換成世界座標 |
| `world/main.js` | 接起來：走路模式／地圖模式、點畫面、門口按鈕、切換小孩 |
| `world/hud.js` | 「進入」大按鈕、「地圖」按鈕、提示文字 |
