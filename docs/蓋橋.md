# 蓋橋（世界設定第 4 步）

## 玩法
- 一開始小公主只能在數學島上走。數學島通到另外四座島的海上，各有**兩條白色虛線**標出橋的位置，中間有一個**浮標「蓋橋・120 歐巴幣」**。還沒連上的島周圍有一圈**淡淡的霧**。
- 打開**建設面板**的方法：點浮標或虛線（電腦、平板都可以，地圖模式也可以）；或走到數學島邊上的**橋頭**，畫面下方出現「蓋到國語島的橋」大按鈕，按它或空白鍵。
- 面板寫出要花多少、現在有多少。**錢不夠**：按鈕是灰的，寫出「還差幾枚」和怎麼賺。**錢夠**：按「蓋橋」，按鈕變成「確定要花 120 歐巴幣嗎？再按一次」，再按一次才真的蓋（避免小孩不小心按到）。
- 蓋下去：歐巴幣馬上扣掉，鏡頭飛去看橋，**木板一片一片落下來**、欄杆跟著長，霧慢慢散掉（約 3 秒）。長好後提示「橋蓋好了！走過去看看國語島吧」，鏡頭回到小公主。蓋橋動畫時小公主先不能走。
- 蓋好以後：小公主可以走過橋。點對岸的島，她會自己**先走到橋頭、過橋、再走過去**。對岸有關卡的話，那座島的建築門口也會出現「進入」按鈕。
- 還沒蓋橋的島照樣能學：走路模式直接點那座島，或按「地圖」點它，就會打開它的建築清單。
- 姐姐和妹妹的橋**分開**：各自的群島、各自的歐巴幣。切換小孩時，橋照那個人蓋過的重畫。

## 橋越蓋越貴（2026-11-27 家長決定）
- 第 1 座 120 歐巴幣，之後每多蓋一座多 120：**第 2 座 240、第 3 座 360、第 4 座 480**（四座一共 1,200）。價錢只看蓋到第幾座，先蓋哪座島都一樣。
- 蓋好第 1 座以後，**第一次打開任何一座橋的建設面板**，先跳出「橋越蓋越貴囉！」說明：四根長條 120／240／360／480，標出「已經蓋好」「現在要蓋」，下面一句小提醒，按「我知道了」關掉。每個小孩只自動跳一次（記在這台裝置的 `elementa.bridgeIntro.<小孩>`）。
- 建設面板寫「這是你的第 2 座橋」，下面有「為什麼變貴了？」按鈕，隨時可以再看一次說明。
- 數字在 `config/economy.json` 的 `build.bridge`：`coins`（第 1 座）、`step`（每座多多少）。`step` 設 0 就變回每座一樣。說明的文字在 `config/text.json` 的 `bridge.intro…`。
- 花多少記在每一筆建設紀錄裡（蓋的時候是多少就扣多少），以後改價錢，已經蓋好的不會重算。

## 錢從哪裡扣
- 網站不記餘額：歐巴幣 = 作答紀錄照規則算出來賺的（`engine/economy.js`）− 建設本記的花費（`engine/build.js`）。
- 建設本存在這台裝置（`localStorage` 的 `elementa.builds`），登入的話也存到試算表新的「**建設**」工作表。
- **同一座橋只扣一次錢**：兩台裝置沒連網時都按了蓋同一座橋，合併後只算最早的那一筆。試算表也不會重複記。

## 參數都在設定檔
| 檔案 | 欄位 | 用途 |
|---|---|---|
| `config/economy.json` | `build.bridge.coins`、`build.bridge.step` | 第 1 座多少、之後每座多多少（現在 120、120） |
| `config/subjects.json` | `bridges` | 可以蓋哪些橋（`from`、`to` 是島的 code）。現在數學島到四座島各一座。要有一頭已經走得到才能蓋，所以之後也可以加「國語島—英語島」這種要先連到國語島才能蓋的橋。不寫就是家到每座島各一座 |
| `config/world.json` | `bridge` | 橋面寬、木板長、欄杆間隔、蓋橋動畫秒數、虛線長短、顏色；`mist` 是淡霧的濃淡、高度、大小 |
| `config/text.json` | `bridge` | 面板、浮標、按鈕、提示的文字 |
| | `login.oldBackend` | 後台還是舊版時，上方小標籤的提示 |

## 程式
| 檔案 | 做什麼 |
|---|---|
| `engine/build.js` | 建設本（不碰畫面，可以用 node 測）：整理紀錄、同一座橋只算一次、可以蓋哪些橋（`bridgePlan`）、從家走得到哪些島（`reachable`） |
| `world/bridges.js` | 3D：橋的位置（`bridgeLine`）、蓋好的橋和木板動畫（`makeBridge`）、虛線和浮標（`makeBridgeSite`）、淡霧（`makeMist`） |
| `avatar/walk.js` | 可以走的地改成「好幾個圓＋橋的長條」（`grounds`）；`routeVia` 找要經過哪些橋頭；`groundAt` 看站在哪一塊地上 |
| `world/islands.js` | 橋要接過來的那條路上不種樹（`paths`），橋頭才不會被擋住；點到東西時多回傳 `bridge` |
| `world/main.js` | 接起來：畫橋和霧、算能走的地（`computeArea`）、建設面板（`openBridge`）、蓋下去（`buildBridge`）、動畫（`stepGrowing`） |
| `world/hud.js` | `showBridge()` 建設面板、`flash()` 暫時的提示 |
| `engine/cloud.js`、`world/account.js` | 建設排進待存清單送到試算表；試算表回傳的建設合併回來（`hooks.onBuild`、`world.builds.merge`＋`world.refreshBuilds`） |
| `backend/Code.gs` | 「建設」工作表、`build` 動作；登入、讀進度、存成績時一起回傳 `builds` |

## 進度後台要更新（backend/Code.gs）
1. 打開試算表 → 擴充功能 → Apps Script。
2. 把 `Code.gs` 的內容整個換成 repo 裡 `backend/Code.gs` 的內容，存檔。
3. （可以不做）上方函式選 `setup` 按「執行」一次，會建好「建設」工作表；不做的話，第一次有人蓋橋時也會自動建。
4. 部署 → 管理部署作業 → 鉛筆圖示 → 版本選「新版本」→ 部署。網址不會變，`config/backend.json` 不用改。

還沒更新也能蓋：橋先記在這台裝置，上方小標籤寫「橋先記在這台裝置，試算表的進度後台要換新版才存得進去」；換好新版後會自動補存（建設不會因為待存清單太長被擠掉）。

「建設」工作表的欄位：時間、小孩、類型（橋）、代號（例如 `math-chinese`）、名稱、歐巴幣、寶石、編號。家長想「拆橋退錢」，把那一列刪掉就好（那台裝置的瀏覽器資料也要清掉，或換一台登入）。

## 安全
- 後台只檢查格式，不重算餘額（餘額是網站照作答紀錄算的）。這是自家用的網站，小孩要作弊得改瀏覽器資料；在意的話，家長可以看「建設」工作表。
- 送到試算表的只有：稱呼、蓋了哪座橋、花多少、時間、編號。
