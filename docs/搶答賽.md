# 遊戲帳篷：搶答賽（games/quiz-race/）

一個人對時間挑戰，不和姐妹對戰。在限定秒數內答越多選擇題越好：答對 +1 分並累積連對；答錯不扣分，但亮出正確答案並扣秒。結束時顯示得分、最多連對、個人最高紀錄，以及這場答錯的題目和解題技巧。

題目由出題模組現出（`engine/generate.js`），每一場都是新題目，只抽選擇題。

## 題庫：哪些關卡放得進去

| 試算表「設定」的「搶答賽題目」 | 程式代號 | 放進題庫的關卡 |
|---|---|---|
| 一開始 | `always` | 這座島所有有選擇題的關卡 |
| 測驗後 | `afterQuiz` | 在測驗塔交過一次整關的（0 分也算；錯題重練不算） |
| 全對後 | `afterPerfect` | 在測驗塔全對過的 |

- 判斷方式和學習屋的開放時機一樣（共用 `engine/cards.js` 的 `cardState`）。
- 有 `make` 的關卡：make 裡出**選擇題**的題型才放進來，題數當權重（例如 `factor-prime*3, factor-factorize*4`，第二種抽到的機會多一點）。填答題型不放。
- 手寫題目的關卡：放它的選擇題，一輪抽完才會再出現，選項順序每次打亂。
- 抽題：題型照權重放進袋子洗牌，抽完一袋再洗下一袋，每種題型都輪得到；同一場不出一模一樣的題目。
- 遊戲帳篷的清單會標出每一關「已放進搶答題庫」「這一關都是填答題」或還要先做什麼，並有「去測驗塔寫這一關」按鈕，交卷後回到帳篷。

**目前（姐姐六上數學）**：出選擇題的題型有 13 種，在 7 個關卡——質數和質因數（unit-01）、先判斷商大小（unit-03）、估商移小數點（unit-06），以及 2026-11-25 新增的裁正方形和公因數（unit-14）、誰除以誰比商（unit-15）、小數點和列式（unit-16）、比值比較求未知（unit-17）。這些關卡裡的填答題不會抽到。兩量關係還沒有選擇題型。要讓更多單元進搶答賽，要在 `engine/generators/math.js` 加選擇題型（錯誤選項照小孩真的寫過的錯法算），再加進關卡檔的 make。

## 秒數和扣秒

- 試算表「設定」的「搶答賽秒數」（30～300）、「搶答答錯扣秒」（0～10），每個小孩分開設定。登入時從試算表拿回來（`account.settingsOf(kid)`，經 `startWorld` 的 `hooks.settingsOf` 傳進群島）。
- 還沒登入、或那一格空白、填錯時，用 `config/game.json` 的預設。帳篷上方會寫現在照哪一種。
- 答完一題到下一題出現之間（看正確答案的時間），時鐘暫停，不算進比賽秒數；扣秒照設定扣，剩下的秒數不夠扣就扣到 0。
- 畫面上正在出、還沒回答的那題，時間到就不算。
- 答錯後會停一下讓小孩看答案（`wrongPauseMs`），也可以按「下一題」提早繼續。
- 鍵盤：1～4 選答案，答錯時 Enter 下一題。

## 成績

- 個人最高紀錄記在 `engine/progress.js`，代號 `game-<島的代號>`（例如 `game-math`），答對題數多才算刷新。登入時跟著試算表「進度」同步，換裝置也看得到。
- 每一場經 `hooks.onResult` 送到試算表「作答紀錄」，類型「搶答賽」（送出時帶 `kind: 'game'`，後台只收 `game-` 開頭的代號）。一題都沒答的場次不記。
- 中途按「離開」（要按兩次）不記成績。
- 歐巴幣（每答對一題 +1、刷新紀錄 +15、一天上限 50）還沒做；`onResult` 的 `info`（`improved`、`firstTry`）和 summary 的 `kind: 'game'` 留給歐巴幣模組判斷。

## 檔案分工

| 檔案 | 負責 |
|---|---|
| `games/quiz-race/race.js` | 參數、試算表規則、題庫、抽題、一場比賽的計分和計時、送後台的精簡紀錄。不碰畫面 |
| `games/quiz-race/race-ui.js` | 準備畫面、3-2-1、作答、結束畫面 |
| `games/quiz-race/race.css` | 搶答賽畫面和遊戲帳篷清單的樣式（共用 `world/quiz.css` 的按鈕、時鐘、錯題清單） |
| `world/hud.js` | 遊戲帳篷清單（規則、題庫、最高紀錄、每一關在不在題庫） |
| `world/main.js` | 把規則、進度、出題模組、畫面接起來 |
| `engine/cloud.js` | 搶答賽成績帶 `kind: 'game'` 送到後台 |
| `config/game.json` | 參數 |
| `config/text.json` 的 `race` 區、`tentBody` | 畫面上的字 |

## config/game.json

| 欄位 | 預設 | 意思 |
|---|---|---|
| `seconds` | 60 | 沒有試算表設定時，一場幾秒 |
| `wrongPenalty` | 3 | 沒有試算表設定時，答錯扣幾秒 |
| `pool` | `afterQuiz` | 沒有試算表設定時的題目來源（`always`／`afterQuiz`／`afterPerfect`） |
| `sheetValues` | `一開始`、`測驗後`、`全對後` | 試算表「搶答賽題目」那一格可以填的字，各對應哪一種 |
| `secondsRange`、`penaltyRange` | [30, 300]、[0, 10] | 能接受的範圍（和後台 `SETTING_DEFS` 一樣） |
| `rightPauseMs`、`wrongPauseMs` | 500、2500 | 答對、答錯後停多久才出下一題（時鐘暫停） |
| `readySeconds` | 3 | 開始前倒數幾秒，0 不倒數 |
| `lowTimeSeconds` | 10 | 剩幾秒時時鐘變紅 |
| `tickMs` | 100 | 時鐘多久更新一次 |
| `levelPrefix` | `game-` | 存成績的代號開頭 |

## 個資

送到試算表的只有：稱呼、`game-math`、「數學島搶答賽」、答對題數、答題數、秒數。每題的答案不送。
