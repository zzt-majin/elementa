# 公路和拜訪（世界設定第 5 步）

## 玩法
- 妹妹的群島（姐姐登入時）放在**南邊 150 公尺外的海上**，上空有一個大牌子「妹妹的群島」。妹妹登入時看到的是姐姐的群島，位置一樣。
- 公路從自己數學島的南邊出發，穿過自然島和社會島中間，接到對方的數學島，長約 109 公尺。**走在公路上比較快**（1.8 倍，大約 14 秒走完）。
- **還沒蓋公路**：海上兩條淡黃色虛線，中間一個浮標「蓋公路・800 歐巴幣 200 鑽石」。打開建設面板的方法：點浮標或虛線、點對方的島，或走到數學島南邊的路口，按「蓋到妹妹群島的公路」或空白鍵。
- 建設面板寫出價錢、現在有多少、還差多少。錢夠了要**按兩次**才蓋（第一次問「確定要花 800 歐巴幣＋200 鑽石嗎？」）。
- 蓋下去：錢和鑽石馬上扣掉，鏡頭飛過去看，路板一塊一塊落下（約 4.5 秒），然後提示「公路蓋好了！」，再跳出「恭喜完成公路！」，按「寫進日記」後日記多一行。
- **公路兩人共有**：誰先存夠錢誰蓋，**錢只從蓋的人扣**，蓋好後兩個人都能走。對方打開公路的面板會看到「公路已經蓋好了（姐姐蓋的）」。

## 去對方的群島（拜訪）
- 蓋好公路後，點對方的島，小公主會沿著公路走過去。站在對方的島上時，畫面上方中間出現黃色標籤「**拜訪中・不記成績**」。
- 能走到哪些島：**對方的數學島，加上對方蓋好的橋連過去的島**。對方的橋只有對方能蓋。對方還沒連上的島一樣有淡霧，點了直接打開清單（沒蓋橋也能學，和自己的群島一樣）。
- 對方的測驗塔、學習屋、遊戲帳篷都能進，題目是**對方的關卡**（例如姐姐去妹妹的島，寫的是四上數學）。面板最上面寫「這是妹妹的島。在這裡……都不記成績」。不顯示對方的成績，也不寫能拿多少歐巴幣。
- **每次開始活動前**（開始測驗、綜合練習、看學習卡、開始搶答賽）都會跳出提醒「你在妹妹的島上：在別人的島上做的活動都不會存成績，也不會拿到歐巴幣、寶石或其他資源」，按「我知道了，開始」才開始，按「先不要」就不開始。
- 拜訪時學習卡**全部打開**，搶答賽的題目用對方**全部的關卡**（家長 2026-11-27 決定）。
- 交卷或搶答結束：寫「拜訪中：這次不記成績，也沒有歐巴幣和寶石。」成績不存在這台裝置、不送到試算表、不算進任何一個人的歐巴幣和寶石。
- 按「地圖」時，如果小公主在對方的群島上，鏡頭拉遠看對方的群島。

## 參數
| 檔案 | 欄位 | 用途 |
|---|---|---|
| `config/economy.json` | `build.road` | 公路價錢（現在 800 歐巴幣＋200 鑽石，2026-11-27 家長改的）。鑽石每天最多拿 30 顆，所以至少要存 7 天 |
| `config/world.json` | `road` | `offset` 對方的群島放在哪（[0, 150]＝往南 150 公尺）、`fast` 公路上快幾倍、路寬、路板長、動畫秒數、虛線、顏色 |
| `config/text.json` | `road` | 面板、浮標、路口按鈕、拜訪標籤、提醒視窗、交卷畫面的字 |
| | `calendar.roadTitle`、`roadBody`、`roadDiary` | 祝賀畫面和日記 |

## 程式
| 檔案 | 做什麼 |
|---|---|
| `engine/build.js` | `ROAD_KEY`（公路的代號固定是 `road`）、`sharedRoad`（看全部小孩，誰最早蓋的）、`roadPrice`、建設本的 `road(kids)` |
| `engine/diary.js` | 公路的里程碑（`other` 是對方的稱呼） |
| `avatar/walk.js` | `speedFactor`：站在有 `fast` 的長條上（不在草地上）就走得比較快 |
| `world/main.js` | 對方的群島（`visitIslands`、`visitBridges`、`visitMist`）、公路（`drawVisit`、`openRoad`、`buildRoad`）、拜訪（`openIsland`／`openBuilding` 的 `visit`、開始前的提醒 `gate`、交卷不存 `visitActivity`） |
| `world/hud.js` | `showNotice()` 提醒視窗、`setVisit()` 上方的拜訪標籤、面板最上面的 `visit-note` |
| `world/camera.js` | `overview(at)` 可以換中心 |
| `games/quiz-race/race-ui.js` | 結束畫面可以顯示 `note`（拜訪中不記成績） |
| `engine/cloud.js`、`world/account.js` | 後台回傳的 `family`（家裡其他小孩的建設）合併進建設本：公路兩人共有、對方的橋畫在對方的群島上 |
| `backend/Code.gs` | 登入、讀進度、存成績、蓋東西時多回傳 `family`（其他小孩蓋的橋和公路，只有建設，沒有成績和密碼） |

## 進度後台要再換一次（backend/Code.gs）
步驟和 `docs/蓋橋.md` 一樣：打開試算表 → 擴充功能 → Apps Script → 整個換成 repo 的 `backend/Code.gs` → 部署 → 管理部署作業 → 鉛筆 → 新版本 → 部署。
沒換的話：同一台裝置上姐姐蓋的公路，妹妹在同一台也看得到；但**換一台裝置**，妹妹就看不到姐姐蓋的公路（要換新版後台才會回傳）。

## 要注意
- 兩台裝置都沒連網時，姐姐和妹妹都按了蓋公路：兩個人都會被扣錢（兩筆都記在「建設」工作表），算公路是最早蓋的那個人的。家長想退錢，把晚的那一列刪掉。
- 從北邊的公路走進對方的數學島時，如果點的地方正好在村子的建築後面，小公主可能會被建築擋住停下來（走路只會沿著擋路的東西滑開，不會自己繞路）。再點一次旁邊就好。
