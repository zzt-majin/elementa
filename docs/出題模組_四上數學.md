## 題型一覽（數學，四上）

| 單元 | 代號 | 內容與針對錯法 |
|---|---|---|
| 一億以內的數 | `g4-bignum-word` | 「比…少／多」逆向大數加減應用題（專治看到「少」就無腦減） |
| | `g4-bignum-compare` | 大數位值組合比大小，例如「6 個千萬＋12 個十萬 ○ 62000000」（選擇） |
| 整數的乘法 | `g4-mul-zeros` | 乘積末尾有幾個 0，含 4×25、8×125 額外進位出 0（選擇） |
| | `g4-mul-dist` | 乘法分配律拆數判斷：拆前數、拆後數、湊整減 1（選擇） |
| | `g4-mul-plan` | 整十整百乘法與優惠方案比划算（專治 350×600 進位錯拼成 183000） |
| 角度 | `g4-angle-special` | 直角（90°）、平角（180°）、周角（360°）與互餘／互補（專治直角平角混淆） |
| 公里與公尺 | `g4-km-calc` | 公里公尺複名數退位減法（如 5 公里 20 公尺－70 公尺）與面對面相距問題 |
| 分數 | `g4-frac-compare` | 假分數與帶分數互換比大小（選擇） |
| | `g4-frac-line` | 分數數線判讀帶分數（專治把 1 又 3/5 看成 2 又 3/5） |
| 除法 | `g4-div3-zeros` | 除以三位數與多個 0 的除法：同消 0 商不變、有餘數時餘數要補回 0 |
