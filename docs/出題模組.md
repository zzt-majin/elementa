# 出題模組（engine/generate.js、engine/generators/）

關卡檔不放固定題目，只寫「出哪幾種題型、各幾題」。每次開始測驗、按「整關再挑戰」、打開學習卡，都會出一份新題目，所以小孩可以一直練、不會背答案。

## 怎麼保證數字對小學生合理

1. **先決定答案，再倒推題目。** 例如小數除法先挑商 83 和除數 6.9，再算出被除數 572.7；兩量關係先挑基準量 640 元和倍數 3/4，再得到比較量 480 元。所以一定除得盡、答案一定整齊。
2. **每種題型有數字範圍**（`config/generators/math.json`）：
   - 小數：最多兩位，除數最多兩位小數；題目裡的數最多三位小數
   - 分數：分母不超過 10～12，答案約到最簡；帶分數的整數部分不超過 5
   - 因數倍數：兩個數都在 100 以內，最小公倍數不超過 240
   - 比：化簡後前項、後項在 15 以內
   - 兩量關係：倍數用課本常見的值（0.75、1.2、4/3、7/4…）；打折用九折到五折；金額是 100 的倍數；答案是整數或一位小數
   - 題目和答案的整數不超過 5000
3. **選擇題的錯誤選項是照常見錯法算出來的**，不是亂數：小數點只移除數、移錯位數；「除數比 1 小商變大」記反；質因數分解混進合數或少乘一個；比大小兩邊相等時故意多出「等於」。
4. **每題都檢查**：選擇題剛好一個正確選項、選項不重複；填答題有答案；文字裡沒有 NaN、undefined。不合格就換一組亂數重出。同一關不會出現一模一樣的題目。
5. **用分數精確計算**（`engine/frac.js`），不用電腦小數，沒有 0.1 ＋ 0.2 的誤差。
6. **同一個種子出同一份題目**（`engine/rng.js`）。錯題重練用的是同一份題目。

## 題型（數學，六上）

| 單元 | 代號 | 內容 |
|---|---|---|
| 因數與倍數 | `factor-prime` | 哪一組全部是質數（選擇） |
| | `factor-factorize` | 質因數分解（選擇） |
| | `factor-gcd`、`factor-lcm` | 最大公因數、最小公倍數 |
| | `factor-apply` | 最多平分（公因數）、下一次同時（公倍數） |
| | `factor-square` | 裁成最大正方形（邊長、幾個）、拼成最小正方形要幾張；張數是相乘不是相加 |
| | `factor-lcm-primes` | 從「甲＝2×3×5」的寫法挑最小公倍數／最大公因數（選擇） |
| | `factor-common-all` | 所有公因數＝最大公因數的所有因數（選擇） |
| 分數除法 | `frac-compare-1` | 不用算，哪一個商比被除數大／小（選擇） |
| | `frac-div`、`frac-div-mixed` | 分數 ÷ 分數、帶分數 ÷ 分數 |
| | `frac-compare` | 比大小：一邊除法一邊乘法（選擇，常有「等於」） |
| | `frac-apply` | 每份多少，可以分幾份 |
| | `frac-part-whole` | 「裝進去的是幾袋」：有多少 ÷ 一整袋（常顛倒） |
| | `frac-compare-div` | 被除數一樣的兩個除法比大小，常有 5/5、2/4 這種「等於」（選擇） |
| 小數除法 | `dec-compare-1`、`dec-compare-n` | 不用算，商比 1 小／比被除數大小（選擇） |
| | `dec-shift` | 小數點一起移，要改成哪個算式（選擇） |
| | `dec-div` | 小數除法（除得盡） |
| | `dec-round` | 四捨五入到小數第二位 |
| | `dec-apply-floor`、`dec-apply-exact` | 最多幾瓶／剩多少、平均每公升 |
| | `dec-point` | 商的小數點放哪裡，錯誤選項是 10 倍、100 倍、十分之一（選擇） |
| | `dec-compare-sign` | a÷b ○ a、a÷b ○ a×b、a÷b ○ a÷c（選擇） |
| | `dec-unit-rate` | 1 公升多少元、1 公尺重幾公斤、1 公斤長幾公尺（有四捨五入） |
| | `dec-part-whole` | 「是喝了幾瓶」：喝掉的 ÷ 一瓶（常顛倒） |
| 比與比值 | `ratio-simplify-int`、`-dec`、`-frac` | 整數比、小數比、分數比化成最簡 |
| | `ratio-value` | 比值 |
| | `ratio-apply`、`ratio-share` | 比例應用、按比例分配 |
| | `ratio-compare` | 用比值比較誰最濃／最深／最甜，前後項的順序會換（選擇） |
| | `ratio-missing` | 相等的比求 (　)，有分數、小數、(　)：1 |
| | `ratio-total` | 知道一部分，求全部（常只算出另一部分） |
| 兩量關係 | `two-base`、`two-sum` | 求基準量、兩量的和 |
| | `two-diff`、`two-diff-given` | 知道相差求基準量、知道比較量求相差 |
| | `two-discount`、`two-percent` | 打折、增加／減少百分率和成數 |

每題的「技巧」都用這一題的數字寫出解法和驗算。

2026-11-25 依姐姐 11 月的新考卷加了 12 種（上表各單元最後幾列），放在 `jie-6a-math-unit-14`～`17`。

## 關卡檔寫法

```
---
id: jie-6a-math-unit-07
kid: 姐姐
grade: 六上
subject: 數學
source: 單元練習
unit: 小數除法
unitOrder: 3
name: 小數除法計算
why: 移小數點、對齊位數；四捨五入要除到下一位
minutes: 10
order: 2
make: dec-div*5, dec-round*2
---
```

- `unit`：單元名稱，測驗塔照它分組，綜合練習也照它勾選。`unitOrder` 是單元的排序。
- `make`：題型代號 ＊ 題數，用逗號分開。
- 關卡檔也可以照舊手寫題目（沒有 `make` 就用手寫的題目）。

## 綜合練習

測驗塔最下面。勾選單元（可以複選，會記住上次勾的），再選題數：`config/mix.json` 的 `presets`，目前是 4 題 8 分鐘、10 題 15 分鐘、15 題 20 分鐘。題數平均分給勾的單元，每個單元從它所有小關的題型抽。每種題數各記一個最佳成績，代號像 `jie-6a-math-mix-10`。

## 要加新題型

在 `engine/generators/math.js` 加一個函式 `(rng, cfg) => 題目`，在關卡檔的 `make` 用它的代號，再跑測試。國語、英語之後各自一個檔，用 `registerTypes()` 加進來。

## 測試

```
node tests/generate.test.mjs          # 每種題型各出 1500 題檢查
N=10000 node tests/generate.test.mjs  # 出更多題
```

測試會從題目文字把算式讀出來，另外重算一次答案（不靠產生器自己的算法），並檢查數字範圍、選擇題只有一個對、同一關不重複、綜合練習題數平均。
