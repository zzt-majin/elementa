# 測驗引擎（engine/quiz.js、engine/progress.js）

測驗塔用的計時、判分、錯題重練。純邏輯，不碰畫面、不含題目和小孩資料，可以單獨拿去別的網站用。

## 檔案分工

| 檔案 | 負責 |
|---|---|
| `engine/levels.js` | 讀關卡檔 .md，變成題目資料 |
| `engine/quiz.js` | 開一場測驗、記答案、倒數計時、判分、挑錯題 |
| `engine/progress.js` | 每個小孩每一關的最佳成績（存在哪裡由外面決定） |
| `world/quiz-ui.js`、`world/quiz.css` | 作答和成績畫面 |
| `config/quiz.json` | 秒數等參數 |
| `config/text.json` 的 `quiz` 區 | 畫面上的字 |

## config/quiz.json

| 欄位 | 預設 | 意思 |
|---|---|---|
| `minutesPerQuestion` | 1 | 關卡沒填 `minutes` 時，一題幾分鐘 |
| `retrySecondsPerQuestion` | 60 | 錯題重練一題幾秒 |
| `lowTimeSeconds` | 60 | 剩幾秒時時鐘變紅 |
| `tickMs` | 250 | 時鐘多久更新一次（毫秒） |
| `warnBlankOnSubmit` | true | 有空白題時交卷要按兩次 |

亂填或沒填的欄位會用預設值。

## 判分規則

- 選擇題：選到 `*` 那個選項才算對。
- 填答題：全形轉半形、去掉空白和千分位逗號後，和任一個標準答案相同就對；兩邊都是數字時數值相等也算對（`.75` = `0.75`）。
- 分數不會自動約分（`9/10` 和 `18/20` 不同）。要接受的寫法，在關卡檔用 `|` 列出。

## 最佳成績

- 答對多的比較好；一樣多時用時短的比較好。
- 錯題重練是訂正用的，不算進最佳成績。
- 目前存在這台裝置的瀏覽器（`localStorage` 的 `elementa.progress`），格式和清單版相同：`{ "姐姐:<關卡id>": { best, used, total, perfectAt } }`。
- 登入和雲端進度做好後，由 `startWorld({ hooks: { onResult } })` 接上，不用改引擎。`onResult(summary, info)` 的 `info` 會告訴你是不是第一次交卷（`firstTry`）、第一次全對（`firstPerfect`）、有沒有進步（`improved`），歐巴幣和錯題小怪可以照這個發。
