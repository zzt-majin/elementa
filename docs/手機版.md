# 手機版

螢幕寬度 640px 以下，或手機橫放（高度 500px 以下）時，`world/phone.js` 會在 `#hud` 加上 `phone`，套用 `world/phone.css`。電腦和平板不受影響。

| 東西 | 手機版 |
|---|---|
| 左上角日曆 | 收起來，只寫「幾月幾日」；點一下打開完整日曆，再點一次收起 |
| 姐妹切換 | 只看得到目前的人（▾）；點她打開，才看得到另一個人和登入狀態（登出也在這裡）。已登入時名字前面有 ☁；存檔有問題（⚠️）或要登入時，登入狀態照樣顯示 |
| 地圖、商店 | 右邊直排的小圓鈕，只有圖示 |
| 時鐘音樂 | 收在右邊的 🎵（關掉音樂時是 🔇）；點一下打開時鐘面板 |
| 下方提示 | 字小一點，6 秒後淡出；提示換了會再出現 |

- 一次只打開一個；點 3D 畫面就全部收起。
- 每次打開網站都是收起的，不記在裝置上，也不上傳。
- 文字在 `config/text.json` 的 `phone`。
