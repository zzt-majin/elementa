# 資源帳本：歐巴幣和寶石（engine/economy.js）

畫面上方會顯示這個小孩現在有多少歐巴幣（金色圓幣）和寶石。交卷、搶答賽結束時，成績下面會寫「獲得 45 歐巴幣、12 顆鑽石！」。

## 不記餘額，每次重算

網站不存「現在有幾枚」。它保留每一次作答的紀錄，每次都照 `config/economy.json` 的規則從頭算一遍，再扣掉蓋橋、蓋公路花掉的。好處：

- 平板和電腦算出來一定一樣。
- 網路斷掉重送、同一筆成績從兩個地方回來，都只算一次（每筆作答有一個編號）。
- 家長改了 `economy.json` 的數字，以前的成績也會照新規則重算。

作答紀錄先存在這台裝置；登入後，試算表「作答紀錄」工作表的紀錄也會合併進來，所以別台裝置寫過的也算數。

## 規則（數字在 config/economy.json）

| 來源 | 歐巴幣 | 寶石（那一科的） |
|---|---|---|
| 一開始（見面禮） | +50（設了歸零時間就不給） | |
| 測驗（還沒全對過的關卡） | 完整 = 10 + 每題 5（7 題 = 45）。全對拿完整，錯 1 題 9 折、錯 2 題 5 折（無條件捨去），錯 3 題以上 0。寫得更好補發差額，最多補到完整 | |
| 測驗每答對一題 | | +1，每關每天只算當天最好的一次 |
| 某一關第一次全對 | （含在上面的完整裡） | 再 +5 |
| 已全對的關卡再寫 | 每關每天 5，一樣照錯幾題打折（錯 1 題 4、錯 2 題 2） | |
| 搶答賽每答對一題 | +1 | 每答對 5 題 +1 |
| 搶答賽刷新最高紀錄 | +15（第一場不算刷新） | |
| 搶答賽一天上限 | 50 | |
| 每科寶石一天上限 | | 30 |
| 錯題重練 | 不給 | 不給 |

**歐巴幣歸零**（2026-11-27 家長要求）：`economy.json` 的 `coinsResetAt` 設成 `2026-11-27T18:00:00+08:00`。這個時間以前的作答都不算歐巴幣、不給見面禮；以前寫過的關卡可以重新拿第一次的獎勵。搶答賽「打破最高紀錄 +15」照真正的最高分比（和畫面上的個人最高紀錄一樣）。寶石照算，不歸零。以後要再歸零，改這個時間就好。

寶石：國語＝紅寶石、英語＝黃金、數學＝鑽石、社會＝藍寶石、自然＝綠寶石。

建設價格（之後的第 4、5 步才會用到）：橋 120 歐巴幣；公路 150 歐巴幣＋60 鑽石。

錯題小怪（+8）和魔王（+100）還沒做，那兩項目前不會發。「哪一天」照裝置的時區算。

## 家裡有哪些小孩：config/family.json

```
{ "kids": ["姐姐", "妹妹"] }
```

還沒有關卡的小孩也會出現在上方的切換鈕，可以登入，看到建造中的島。名字要和試算表「帳號」工作表一樣，只用稱呼，不寫真名。

## 進度後台要更新（backend/Code.gs）

這一版的後台多做了兩件事：「作答紀錄」第 10 欄存每筆作答的「編號」，同一個編號不會存兩次；登入、讀進度、存成績時，會把這個小孩的作答紀錄一起傳回網站。

更新步驟：

1. 打開試算表 → 擴充功能 → Apps Script。
2. 把 `Code.gs` 的內容整個換成 repo 裡 `backend/Code.gs` 的內容，存檔。
3. 上方函式選 `setup`，按「執行」一次（會在「作答紀錄」第 10 欄補上標題「編號」，已填的內容不會動）。
4. 部署 → 管理部署作業 → 鉛筆圖示 → 版本選「新版本」→ 部署。網址不會變，`config/backend.json` 不用改。

還沒更新後台也能用：網站照樣算本機的紀錄，只是看不到別台裝置寫過的。

## 給程式

```js
import { economyRules, computeWallet, canAfford, createLedger } from './engine/economy.js';
const rules = economyRules(economyJson);
const w = computeWallet({ history, spends, rules, islandOf });
// w.coins、w.gems.math、w.events（每筆作答各賺多少）
canAfford(w, rules.build.bridge); // { ok, short: { coins, gems } }
```

一筆作答：`{ id, at（毫秒）, level, island, score, total, kind: 'level' | 'retry' | 'game' }`。試算表回來的紀錄沒有 island，由 `islandOf` 從關卡代號找。
